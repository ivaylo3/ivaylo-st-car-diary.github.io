# Car Diary

Лична сервизна книжка за автомобил: срокове за обслужване, документи и такси, гуми, история и записки.

**В това репо няма лични данни.** Тук е само кодът на приложението. Всички данни (книжката, снимките, историята на промените) се пазят във Google Drive на собственика, в папка `CarDiaryPersonal`, и се четат директно от браузъра след вход с Google.

## Сигурност
- Вход само с Google; OAuth клиентът е в режим *Testing* с един разрешен потребител.
- Достъп до Drive само с `drive.file` – приложението вижда единствено файловете, които само е създало.
- Допълнителна проверка в приложението: приема се само акаунтът на собственика (пази се като SHA-256 отпечатък, не като имейл).

## Структура
- `app/` – приложението (публикува се в GitHub Pages)
- `.github/workflows/pages.yml` – автоматично публикуване при промяна в `main`

## Известия
- Всеки ден около 11:00 (с резервни пускания до 22 ч, ако GitHub закъснее; телефонът показва всяко напомняне само веднъж) българско време GitHub Actions (`.github/workflows/notify.yml`) изпраща празен сигнал до регистрираните устройства. Сигналът не носи данни: всяко устройство само изчислява какво да покаже от собственото си копие на сроковете.
- Ключове: генерират се веднъж с `npx web-push generate-vapid-keys`.
- В *Settings → Secrets and variables → Actions*:
  - променлива (Variables) `VAPID_PUBLIC_KEY` – публичният ключ; вгражда се в приложението при публикуване;
  - секрет `VAPID_PRIVATE_KEY` – частният ключ за подписване на сигнала;
  - `PUSH_SUBSCRIPTIONS` – кодовете на устройствата, по един на ред (от приложението: Интервали → Известия).
- Ръчна проба: *Actions → Известия → Run workflow → test*.

## Километраж от MyŠkoda (по желание)

Всяка сутрин около 8:30 (до 4 опита до 9:00, с резервни пускания до 13 ч, ако GitHub закъснее) работният процес „Километраж от MyŠkoda“ пита официалното
[MyŠkoda Public API](https://public.api.connect.skoda-auto.cz/docs) за последния километраж, който колата е изпратила.
Резултатът се криптира (AES-256-GCM, ключ от паролата `ODO_SECRET`) и се публикува в клона `odo-data`
(само последната версия, без история). Ако колата още не е изпратила данни, процесът не е „грешка“ –
пази предишния километраж и записва само неуспешния опит. Грешка (и имейл) има само при проблем с ключа/VIN.

Бутонът за синхронизация в приложението пуска същия процес веднага (1 заявка) чрез GitHub токен с право
само **Actions: Read and write** за това репо, въведен на устройството в „Настройки“.

Нужни тайни в **Settings → Secrets and variables → Actions**: `SKODA_API_KEY` (ключ от MyŠkoda), `SKODA_VIN`, `ODO_SECRET`.
Логовете на процеса не съдържат стойности – само HTTP статус, кодове и оставащи заявки.
